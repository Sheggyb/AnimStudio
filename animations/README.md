# Animation packs

Your animation packs live here: `.glb` files full of moves. ✦ Moves offers every move in them on any character.

The easy way to add them is the AnimStudio start page: press **＋ Add animations**, or drop files on the *Animation packs* section.
- **Mixamo** `.fbx` downloads (30 fps, *In Place* for walks and runs) become a *Mixamo Pack*. Later downloads are added to it.
- **Packs** such as Quaternius' free *Universal Animation Library* are added as they are.

You can also copy `.glb` packs into this folder yourself and restart AnimStudio.

Nothing in this folder is part of the repository (except this note). Check each source's terms before sharing packs.
